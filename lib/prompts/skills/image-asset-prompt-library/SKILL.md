# 图片资产提示词库

## 概述

调用本技能以复用用户沉淀的图片资产提示词方法：人物、场景、道具三类资产，以及跨类别共用的媒介、摄影、光影、材质、构图和负面约束模块。优先输出可直接用于图像生成的完整中文提示词；保留可替换字段，避免将互斥风格混入同一提示词。

本技能基于 986 条历史提示词的分类索引构建。完整索引见 `references/asset_catalog.csv`，归类说明与高频结构见 `references/classification-report.md`，三类提示词模块见 `references/prompt-frameworks.md`。

## 触发场景

在以下请求中使用本技能：

- 创建人物设定、角色肖像、角色三视图、服装或影视角色资产提示词。
- 创建室内、室外、建筑、自然、现代都市、奇幻世界观等场景提示词。
- 创建武器、饰品、器物、产品、包装、家具或陈列道具提示词。
- 为人物、场景与道具建立同一世界观、镜头语言、光影、色彩与材质规范。
- 整理或增量归类新的图片资产提示词。

## 工作流

### 1. 识别主资产

按画面主体而非偶然出现的词语判定类别：

- 主体是人、角色设定、五官、服饰或姿态：选择“人物”。
- 主体是空间、地点、建筑、自然环境或环境叙事：选择“场景”。
- 主体是单一物件、产品、武器、器物、饰品或陈列品：选择“道具”。

人物出现在场景里、道具出现在场景里，不改变场景主类。每个请求仅指定一个主资产；其余内容记录为关联资产或约束。

### 2. 选择结构框架

读取 `references/prompt-frameworks.md` 中对应类别。按需求组装模块：

1. 主体与世界观定位。
2. 结构与可见信息。
3. 外观、材质与细节。
4. 镜头、构图、画幅。
5. 光影、色调、媒介质量。
6. 一致性与负面约束。

除非用户明确要求，不堆叠“电影级、8K、杰作”等泛化修饰词；把重点落在可观察、可控的结构、材质、摄影和光线条件上。

### 3. 建立跨资产一致性

组合多个资产时，先确定共享锚点：世界观、时代地域、材质词典、色彩比例、光源方向、镜头系统与画幅。再分别生成各资产提示词。

人物三视图须固定身份特征、脸部结构、肤色、发型、体型、服装和光照，并默认采用左右分区标准版式（左侧 1/3 正脸特写 + 右侧 2/3 三视图，详见 `references/prompt-frameworks.md`）；空间或道具多视图须固定尺度、结构、材质与光源方向。

### 4. 输出

默认按以下顺序输出：

- 一行：资产类型与意图摘要。
- `完整提示词`：分模块、可直接复制。
- `负面约束`：仅列与本次生成明显相关的冲突项。
- `可调参数`：给出 3–6 个可替换变量。

用户仅要求灵感或短提示词时，压缩为“核心主体 + 关键结构 + 材质/风格 + 镜头/光线 + 约束”，不要机械输出完整长模板。

## 分类与检索规则

- 需要查看样本或统计时，读取 `references/classification-report.md`。
- 需要按分类、关键词或编号查找历史条目时，读取或筛选 `references/asset_catalog.csv`。
- 新增提示词时，运行 `scripts/classify_prompts.py` 生成更新后的索引；将低置信度或混合资产条目复核后再定类。
- 以“主资产类别 + 子类 + 风格/世界观 + 用途”描述新条目，例如“场景 / 室内建筑 / 现代都市写实 / 住宅玄关”。

## 质量检查

在交付前检查：

- 画面主体是否唯一、明确，且与主资产类别一致。
- 构图、镜头、光源是否互相兼容。
- 人物的年龄、外形、服装与气质是否存在冲突。
- 场景的空间结构、陈设、时代与材料是否自洽。
- 道具的功能、尺度、结构、材质与使用痕迹是否自洽。
- 是否明确不需要的人物、文字、水印、重复物体、畸变或不一致视角。
