# 资产提示词分类报告（首版）

## 数据范围

- 来源：`query_2_260822200846.csv`
- 总条目：986
- 空白条目：0
- 单条字符数：最短 4；中位数约 1,007；最长 5,000
- 语言：以中文为主，包含部分英文电影/场景描述。
- 自动首版索引：人物 761 条、场景 201 条、道具 24 条；其中 373 条为低置信度混合资产，需按画面主资产人工复核。

> 自动索引服务于检索和初步归档，不代表对原始提示词的最终语义裁决。由于场景提示词常出现“无人物/无道具”等否定约束，且人物常携带道具，不能将关键词出现次数直接等同于资产类别数量。

## 主要发现

1. 素材库已经不是简单的关键词库，而是可复用的“生产级提示词规范”。多数长提示词含有结构化标题和控制约束。
2. 三大类存在天然交叉：场景往往带有道具陈设，角色往往携带服装道具。因此，归类必须以“画面主资产”优先，关联资产作为辅助标签。
3. 高频结构显示出两条成熟的写作路线：
   - 人物：身份/外观/服装 → 解剖与材质 → 商业或档案摄影控制。
   - 场景：风格/摄影 → 光影与色调 → 空间架构 → 环境叙事与陈设。
4. 资产库的优势是写实、影视化与高密度材质描述；首版 Skill 因此以“结构模块 + 一致性控制”为核心，而不是机械复用整段文本。

## 三层分类法

### 一级：主资产

| 主类 | 判定方式 | 典型需求 |
|---|---|---|
| 人物 | 人、角色、肖像、服装、姿态、身份识别为主体 | 角色三视图、肖像、角色设定 |
| 场景 | 空间、地点、建筑、自然环境或环境叙事为主体 | 住宅、地牢、城市街景、森林 |
| 道具 | 单件或成套物品、产品、武器、器物为主体 | 仪式武器、产品包装、饰品、家具 |

### 二级：建议子类

| 主类 | 子类 | 关键字段 |
|---|---|---|
| 人物 | 角色设定/三视图 | 年龄、性别、体型、面部、发型、服装、姿态、一致性 |
| 人物 | 肖像/人像 | 骨相、眼神、皮肤、发丝、镜头、背景、表情 |
| 人物 | 服装与造型 | 廓形、材料、工艺、层次、配饰、磨损、气质 |
| 场景 | 室内建筑 | 功能、空间结构、硬装、家具陈设、人工光源、色彩 |
| 场景 | 室外/自然 | 地貌、植被、天气、时间、空气介质、尺度、远近景 |
| 场景 | 奇幻/历史建筑 | 世界观、功能空间、建筑语汇、材质、仪式陈设、氛围 |
| 场景 | 现代都市/商业 | 地域、建筑类型、生活/商业叙事、写实摄影系统 |
| 道具 | 武器/仪式器物 | 功能、结构、尺度、材料、工艺、磨损、符号 |
| 道具 | 产品/包装 | 品类、品牌调性、材质、包装结构、陈列、商业布光 |
| 道具 | 饰品/工具/家具 | 外观、功能部件、制造逻辑、材料、使用痕迹、场景关系 |

### 三级：跨类标签

- 世界观/题材：现代都市、自然、奇幻神话、历史、中世纪、哥特、影视写实。
- 用途：角色资产页、概念设定、环境建立镜头、产品展示、叙事陈设。
- 视觉媒介：真人电影、商业摄影、建筑摄影、档案摄影、概念艺术。
- 控制维度：画幅、机位、焦段、构图、光源方向、色温、主辅点缀色、负面约束。

## 高频结构字段

| 字段 | 观察 |
|---|---|
| 面部特征、年龄、发型、服装、体型特征、气质描述 | 人物资产的核心识别字段，出现频率最高 |
| 媒介与视觉风格、摄影与光学参数、光影与色调系统、空间与场景架构 | 现代写实场景常见的标准化段落 |
| 场景定位、空间结构、建筑细节、陈设细节 | 奇幻/历史场景常见的标准化段落 |
| 负面提示词 | 多个题材均使用，建议保留但按资产类型精简 |

## 使用原则

1. 先确定主资产，再选子类，最后补齐跨类标签。
2. 将“人物/场景/道具”作为并列资产清单时，分别写提示词，再通过共享光线、色彩、材质与世界观字段统一。
3. 让每个段落承担一个可见的控制目标；删除与画面无关或互相冲突的修饰词。
4. 对自动分类置信度低的条目进行人工复核，尤其是同时含有角色、空间与陈设的叙事提示词。
