# 图片资产提示词框架

## 1. 人物资产

### 适用子类

- 角色设定页与角色三视图
- 近景肖像、半身或全身人像
- 写实人物、影视角色、奇幻角色、职业人物
- 服装、发型、妆容或神态设计

### 模板

```text
【资产定位】[时代/地域/世界观]中的[角色身份或职业]，[整体风格与气质]。
【角色信息】年龄：[ ]；性别呈现：[ ]；体型：[ ]；身份/经历：[ ]。
【面部与识别特征】脸型、骨相、眼睛、鼻嘴、肤色、标志物；明确可跨图保持的特征。
【发型与妆容】颜色、长度、结构、发丝质感、妆容重点。
【服装与配饰】廓形、层次、材料、工艺、功能性、磨损或洁净程度。
【姿态与表情】站姿/动作、视线方向、情绪强度、手部状态。
【画面布局】[画幅]，[景别/视角/构图]；如为三视图，固定正面、侧面、背面与一致的姿态。
【摄影与布光】[相机/镜头或视觉媒介]，[主光方向/柔硬度/补光]，[背景]。
【一致性约束】固定身份特征、面部比例、发型、体型、服装、材质、姿态与光线方向。
【负面约束】避免文字、水印、额外肢体、重复人物、五官漂移、错误服装结构。[按需补充]
```

### 人物高频模块

历史库中，人物类最稳定的字段依次为：年龄、性别、体型特征、面部特征、发型、服装、气质描述。角色资产页常见的是“近景头像 + 全身多视图”的布局，并强调面部解剖、皮肤微观纹理、发丝、服装结构与统一布光。

### 角色三视图 / 资产页标准版式

当需求为“角色三视图、角色资产页、角色设定图”时，默认采用以下左右分区版式（历史库中高频出现，请直接沿用，勿临时改写）：

- 左侧（约占画面宽度 1/3）：角色正脸特写（Bust Shot），眼睛平视镜头，表情中性沉静，无情绪流露。
- 右侧（约占画面宽度 2/3）：全身三视图横向均匀排列，从左至右依次为正视图、侧视图（90° 纯侧面）、背视图。
- 三视图身高完全一致、头身比例统一；服装图案与结构在各视图中空间连续对应；视图之间留均等间距。
- 所有视图保持完全一致的身份特征、面部结构、五官比例、发型、肤色、体型、服装、材质、姿势与表情；双手自然下垂，标准站姿。

变体：若重点在服装，可将左侧特写替换为“放大正面服装展示图（标准 A-pose 站姿，头部可入镜或不入镜）”。道具资产页同理：左侧 1/3 为核心部位近距离特写，右侧 2/3 为多角度视图。

## 2. 场景资产

### 适用子类

- 室内建筑：住宅、办公、酒店、公共空间、审讯/功能空间
- 室外建筑：街道、城市、园林、遗址、宫殿
- 自然环境：山地、森林、海岸、冰雪、荒漠
- 奇幻与历史：神殿、地牢、祭祀空间、王宫、异世界遗迹

### 模板

```text
【场景定位】[时代/地域/世界观]中的[地点名称与功能]，[核心情绪与视觉反差]。
【空间结构】尺度、开合关系、动线、层级、入口/窗洞/顶部、纵深、视觉中心与对称/非对称逻辑。
【建筑与地貌】主体材料、结构构件、表面状态、风化或维护痕迹。
【陈设与叙事】关键物件、数量与位置、使用痕迹；避免无目的的堆叠。
【环境与氛围】天气、时间、空气介质、植被或环境特征。
【摄影与构图】[画幅]，[机位/焦段/景别]，[透视与构图]。
【光影与色调】主光来源、方向、色温、明暗对比、主/辅/点缀色比例。
【质量与约束】真实尺度、材质受光准确、画面无人物/是否允许人物、无文字水印、无结构畸变。
```

### 场景高频模块

现代写实场景常用“媒介与视觉风格 → 摄影与光学参数 → 光影与色调系统 → 空间与场景架构 → 资产细节与环境叙事”的顺序。奇幻场景常用“场景定位 → 空间结构 → 建筑细节 → 陈设细节 → 光影氛围”的顺序。

## 3. 道具资产

### 适用子类

- 武器、护甲、仪式器物、书籍与工具
- 饰品、服装配件、收藏品
- 消费产品、包装、产品陈列
- 家具、设备与场景关键道具

### 模板

```text
【道具定位】[世界观/品牌/时代]的[物件名称]，用于[功能或叙事用途]。
【外形与尺度】整体轮廓、比例、主要部件、尺寸关系、正反面/拆解或多角度要求。
【结构与工艺】连接方式、开合方式、功能部件、制造工艺与细节逻辑。
【材质与表面】主材、辅材、纹理、反射特性、磨损、污渍或使用痕迹。
【图案与符号】纹样、色彩、标识；仅在用户要求时包含可读文字。
【陈列与构图】背景、支撑方式、悬挂/平放、视角、景别、画幅。
【摄影与光线】产品摄影/档案摄影/电影写实，光源方向、软硬、阴影与高光控制。
【负面约束】避免变形、重复零件、功能结构错误、漂浮、文字水印、错误透视。
```

### 道具高频模块

道具必须优先描述“功能—结构—材料—尺度—陈列”的因果链。作为场景陈设时，减少单品级的摄影参数，转而描述其数量、位置、与空间的比例和叙事作用。

## 4. 共享控制模块

### 风格与媒介

优先明确一个视觉路线：真人电影、商业产品摄影、写实建筑摄影、概念艺术或插画。不要将“纪实写实、棚拍档案、戏剧化电影光效”在未说明目的的情况下混用。

### 摄影与构图

指定画幅、机位、焦段或视角、景别、透视和主体位置。需要复刻时，区分“保留机位/构图逻辑”与“复制具体图像”。

### 光影与颜色

指定主光源、方向、色温、阴影软硬和总体明暗关系。配色使用主色、辅助色、点缀色及大致占比，避免仅列颜色名。

### 负面约束

仅写必要约束：无文字、无水印、无额外主体、比例正确、结构合理、材质受光正确、画面整洁。人物需额外限制脸部漂移、肢体异常和服装错位；空间需限制结构畸变和透视冲突；道具需限制重复部件和功能结构错误。
