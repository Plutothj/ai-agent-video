# 生视频提示词导演框架

## 任务路由

| 任务 | 优先结构 | 关键控制点 |
|---|---|---|
| 真人竖屏短剧 | 情绪节拍 + 表演反应镜头 | 人物关系、自然表演、台词口型、空间连续 |
| 3D 漫剧 | 资产锁定 + 风格化镜头 | 角色/场景参考图、模型材质、骨骼/布料、光影统一 |
| 武侠/奇幻动作 | 动作段落 + 节奏曲线 | 起势、对峙、爆发、收招；机位可执行、物理合理 |
| 口播/访谈 | 单人主体 + 信息节奏 | 口型、目光、手势、景别变化、留白 |
| 公益/纪实/服务 | 环境建立 + 群像情绪 | 真实场景、人物行为自然、温暖但不过度广告化 |

## 项目级全局约束

仅在一个序列的开头写一次。固定下列要素：

1. 成片类型与视觉媒介：真人写实、3D 漫剧、风格化 CG 等。
2. 画幅、单段时长上限和拆镜策略。
3. 角色、场景和道具的资产绑定规则。
4. 光影、色彩、镜头系统和材质基准。
5. 连续性规则：角色数量、服装、站位、道具、曝光、时间与空间。
6. 文字策略：`无字幕无水印`、`允许 UI 但禁止字幕和水印`，或明确允许的文字内容。不得混用。
7. 声音策略：静音、环境音、台词口型同步或配乐；不得出现“无音乐”和“音乐回落”的冲突。

## 资产注册表

在写镜头前，明确资产与引用范围：

```text
场景：scene_forest = @图片1，固定森林场景；保持树体、地面、方向与主光不变。
角色：hero = @图片2，角色身份形象 75%，动作神态 25%。
角色：demon = @图片3，保持体型、服装、角部特征与眼睛颜色一致。
道具：token = @图片4，仅作为手持道具；保持尺寸与材质。
站位：hero 位于画面左侧三分之一，demon 在右后景；只锁定相对位置，不继承参考图服装。
```

禁止在同一镜头把同一引用登记为不同角色或不同道具。引用未定义时先补资产表。

## 单镜头模板

```markdown
## 镜头 {编号}｜{起止时间}
- 叙事目标：{观众此刻应该接收的信息或情绪}
- 景别：{全景/中景/近景/特写}
- 机位与构图：{平视/仰视/俯视；人物位置；前中后景}
- 运镜：{固定/慢推/跟拍/摇镜/拉镜；速度与停止点}
- 画面动作：{单一主动作 → 可见反应 → 收束姿势}
- 焦点与景深：{焦点对象；景深逻辑}
- 光影与色彩：{主光方向、色温、动态变化}
- 声音与台词：{环境声/同期动作声/台词；口型规则}
- 衔接：{与上一镜的连续点；下一镜的切出点}
```

每镜只承载一个核心动作或一个信息转折。复杂打斗拆成“预备 → 发起 → 接触 → 结果/反应”镜头组，避免在一个镜头中同时要求多重高速动作、变身与大范围场景变化。

## 镜头原子

### 景别与叙事功能

- 大全景/全景：建立地点、人物关系与危险尺度。
- 中景：交代动作和人物互动。
- 中近景/近景：呈现情绪转折、手部交互、关键道具。
- 特写/大特写：锁定眼神、触发物、微动作或信息揭示。

### 运镜选择

- 固定：审讯、压迫、口播、强表演镜头。
- 慢推：发现、紧张累积、情绪靠近。
- 跟拍：行走、追逐、动作主体移动。
- 环绕：展示人物关系或仪式感；限制为缓慢、明确的角度变化。
- 快推/快切：高潮信息揭示；前后镜需保持主体、光线和方向连续。

### 动作表述

按“起始姿势 → 主动作 → 受力/视觉反应 → 结束姿势”描述。标注接触对象、受力方向和视线方向。避免使用“做一系列炫酷动作”这类不可执行描述。

### 紧凑镜头语法

单镜头机位可压缩为「景别 + 机位角度 + 运镜 + 是否运动」的固定语序，例如：`近景，平视，固定镜头，无运动`、`近景，左侧拍平视，固定镜头`、`特写，俯视，缓慢跟随`。写完整模板与写紧凑指令时保持同一语序，便于模型稳定解析。

## 约束包

### 通用稳定性

- 动作连续，无跳帧、撕裂、漂移或不合理速度变化。
- 人物、道具与场景遵守遮挡、接触、重力和尺度关系。
- 关键表情、手部动作和道具位于画面安全区。

### 人物连续性

- 固定脸部、发型、服装、配饰、体型与角色数量。
- 禁止分身、重复角色、五官错乱、肢体/关节崩坏。
- 需要说话时，要求自然口型、呼吸、眨眼和微表情；台词短且可在镜头时长内完成。

### 3D 漫剧质量

- 禁止低模、廉价网游感、UV 拉伸、贴图错位、材质闪烁、骨骼扭曲、布料穿透和游戏 UI。
- 保留风格化接触阴影、正确环境投影与统一材质密度。
- 单镜头时长≥2s，时长无缝衔接无重叠；全程无 AI 卡顿、无跳帧、无画面撕裂。
- 场景无跳变、无杂物乱入、无背景物体浮空、无模型穿插。
- 曝光稳定，不因镜头切换产生明显亮度变化；无摄影棚补光感、无商业广告灯光，不过曝高光、不过度提亮暗部。
- 无刻意轮廓光、无发光边缘、无发光特效残留。

### 真人写实质量

- 避免蜡像感、塑料皮肤、过度磨皮、异常高光和不自然商业棚光。
- 保留真实皮肤纹理、自然衣物运动与环境光反射。

### 权重与锁定约束

历史库高频使用「权重标记 + 兜底锁定」两层写法，按需使用：

- 权重：对最关键的约束追加 `:1.5`（如 `最终强制锁定约束:1.5`），提升其被遵守的优先级。只在真正关键的约束上加，避免全篇滥用稀释作用。
- 兜底锁定：对最易翻车的点（无字幕水印、无同款分身/重复人物、无穿模跳帧）在结尾用「再次强调 + 严格遵守 + 违反即无效」的锁定句式二次强调。

## 冲突检查

交付前逐项检查：

1. `无字幕/无文字` 与 `字幕/UI/聊天文字清晰可见` 是否冲突。
2. `无音乐` 与 `配乐、音乐回落` 是否冲突。
3. 角色称谓、引用编号和人数是否一致。
4. 相邻镜头是否保持场景、服装、道具、主光和视线方向连续。
5. 单镜头时长是否足够承载台词与动作。
6. 真人写实、3D 漫剧、强虚拟 UI 等风格是否被无理由混用。
7. 是否把项目级约束重复塞进每个镜头；重复内容应上移到项目级。
