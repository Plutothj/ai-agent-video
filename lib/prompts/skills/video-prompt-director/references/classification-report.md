## 高价值结构

### 1. 项目级全局约束

高频包含：画幅、时长、风格、人物与场景稳定性、无字幕/水印、动作质量、光影基准等。应从每镜文本中抽离，作为序列开头只写一次的“全局守则”。

### 2. 资产与参考图绑定

`@图片`、`<主体>`、角色权重、场景锁定和站位参考是库中成熟的生产习惯。建议以资产注册表形式显式声明，避免图片编号或角色名称在镜头中混淆。

### 3. 分镜执行描述

多数条目已包含景别、运镜、机位、动作、光影、景深、音效/台词与转场。它们是本 Skill 的核心，应按镜头标准模板拆解，便于逐段生成与连续剪辑。

### 4. 生成缺陷规避

提示词累计了角色漂移、穿模、跳帧、口型异常、低模、UV/材质错误、滑步等失败案例的规避经验。建议按真人/3D/动作三套约束包按需调用，避免全量堆叠稀释镜头重点。

## 需要治理的问题

1. **模板格式混用**：项目级约束、镜头字段与多镜头脚本的写法不统一。
2. **重复与近似重复**：同一镜头结构常仅替换角色、场景或图片编号；建议模板化，而不是保留大量近似正文。
3. **指令冲突**：无文字与 UI 文字、无音乐与要求配乐、真人写实与强虚拟视觉等要求有时并存。
4. **约束冗余**：同一全局规则反复写入每一镜，会挤占模型对动作和镜头重点的注意力。
