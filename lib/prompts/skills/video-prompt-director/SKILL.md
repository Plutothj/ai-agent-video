# 生视频分镜导演与稳定性控制

## 概述

调用本技能以将剧情梗概、角色/场景参考图与创意要求转化为可执行的视频生成分镜提示词。优先产出“项目级约束 + 资产表 + 逐镜头指令 + 冲突检查”，而不是把所有规则混进一个冗长段落。

本技能基于 657 条沉淀视频提示词构建。读取 `references/classification-report.md` 了解资产分布与治理重点；读取 `references/video-prompt-framework.md` 组装镜头和约束；使用 `references/video_prompt_catalog.csv` 按类型、技术标签或关键词检索原始案例。

## 触发场景

在以下请求中使用本技能：

- 编写真人竖屏短剧、3D 漫剧、武侠/奇幻动作、口播/访谈或公益纪实的视频提示词。
- 将故事梗概、脚本或台词拆为可逐段生成的分镜。
- 引入 `@图片`、主体、场景、道具或站位参考，并要求角色与场景稳定。
- 统一多镜头的角色、服装、光影、镜头方向、道具与声音策略。
- 归类、去重、提炼或质检已有视频提示词资产。

## 工作流

### 1. 确定项目边界

先明确：视频类型、目标平台画幅、总时长、单段生成限制、是否需要台词或环境音、是否需要参考图。信息缺失时，做最少量的合理假设并在输出中列出。

### 2. 选择类型与风格包

根据任务选择一个主类型：真人短剧/叙事、3D 漫剧/动画、武侠/奇幻动作、口播/访谈、公益/纪实/服务。只在确有叙事理由时混用风格。将具体 IP 对标转译为可执行的视觉特征，如“国风 3D 漫剧、低饱和、柔和体积光、统一材质”，避免让成片依赖具体作品名称。

### 3. 先建资产注册表

在写镜头前，登记角色、场景、道具、参考图片与相对站位。为每个资产明确“形象锁定”和“动作神态”优先级。禁止未定义的图片编号或同一引用在同镜头承担互相矛盾的身份。

### 4. 拆分叙事节拍

将故事拆成开场建立、信息揭示、冲突/行动、反应或高潮、收束。每一个镜头只承载一个核心动作或信息变化。复杂动作拆镜，不要要求模型在数秒内同时完成多人高速打斗、变身、大范围场景切换和长台词。

### 5. 写入镜头指令

遵循 `references/video-prompt-framework.md` 的单镜头模板，至少给出：叙事目标、景别、机位构图、运镜、画面动作、焦点/景深、光影、声音/台词和衔接点。

### 6. 选择精简约束包

将通用稳定性、人物连续性、3D 漫剧或真人写实质量约束按需加入项目级规则。避免在每镜重复粘贴所有负向词。仅在镜头特有风险（如手部道具接触、快速打斗、强光变化）出现时补充镜头级约束。对最关键约束可用「权重 `:1.5` + 结尾兜底锁定」强调（见 `references/video-prompt-framework.md`）。

### 7. 执行连续性与冲突检查

检查文字策略、音频策略、人物数量、资产引用、台词时长、风格兼容性，以及相邻镜头中的服装、站位、主光、视线方向、道具状态是否连贯。检测到冲突时，先提示并提供一种明确的修正方案，再输出最终版本。

## 默认输出格式

```markdown
## 项目级约束
- 类型与视觉风格：
- 画幅、时长与拆镜：
- 场景与角色连续性：
- 文字与声音策略：
- 适用质量约束：

## 资产表
- 场景：
- 角色：
- 道具：
- 站位/空间关系：

## 镜头 01｜0s–4s
- 叙事目标：
- 景别 / 机位 / 构图：
- 运镜：
- 画面动作：
- 焦点与景深：
- 光影与色彩：
- 声音与台词：
- 衔接：

## 连续性与冲突检查
- 通过项：
- 待确认项：
```

用户只要一个短视频提示词时，压缩为“资产表 + 一个项目级约束段 + 单镜头模板”，不要强行输出多镜头脚本。

## 资产分类与检索

- 需要查看原始案例时，筛选 `references/video_prompt_catalog.csv` 的 `primary_type`、`techniques`、`title` 或 `prompt`。
- 新增 CSV 资产时，运行 `scripts/classify_video_prompts.py input.csv output.csv` 生成索引；把低置信度和跨类型条目标注为待复核。
- 以“一级类型 / 二级类别 / 镜头用途 / 风格包”命名新条目，例如“3D 漫剧 / 国风玄幻 / 妖气揭示特写 / 风格化电影光”。

## 交付检查

交付前确认：

- 主体、动作和镜头意图是否明确且单一。
- 台词能否在镜头时长内自然说完，且是否需要口型同步。
- 引用图片、角色人数、道具状态和站位是否一致。
- 文字、UI、字幕、水印与音乐策略是否无冲突。
- 单镜头运动是否可执行，且是否需要拆镜降低复杂度。
- 资产、主光、色调、视线和运动方向是否在相邻镜头间连续。
