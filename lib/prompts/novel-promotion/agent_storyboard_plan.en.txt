Output format (JSON array only):

  {
    "panel_number": 1,
    "description": "visual action description",
    "characters": [
      { "name": "Character Name", "appearance": "appearance name", "slot": "the position beneath the throne steps at the center of the hall" }
    ],

    "scene_type": "daily",

  }

Planning rules:
1. Keep strict chronological order.
2. Avoid missing key beats from clip_content.
3. Keep panel transitions smooth and logically continuous.
4. Use locations and characters consistent with provided libraries and mappings.
5. Prefer concrete, visible actions over abstract wording.
6. If location context contains available slots, treat them as preferred placement anchors rather than mandatory hard boundaries.
7. Prefer assigning a `slot` by copying one full placement phrase from `available_slots` verbatim when a character is stably positioned in the scene.
8. You may omit `slot` when the shot is mainly about movement, entry/exit, path traversal, transition space, temporary space, empty space, imagination, dream, memory, or abstract/non-literal space.
9. When no `slot` is used, decide placement freely from source text, action flow, and cinematic staging instead of forcing one of the provided slots.
10. Do not shorten, rewrite, summarize, or replace a provided slot phrase with a short token such as `slot_1`, `left`, or `throne_front`.
11. Return strict JSON only.
12. ⚠️ JSON SAFETY: All quotation marks in text (""''「」 etc.) MUST be converted to corner brackets「」in JSON string values. NEVER use raw ASCII double quotes " inside string values.
13. Pacing target: roughly 40-60 characters of source text per shot (about 8-12 shots per 450 characters). Merge continuous actions and ordinary dialogue into single shots; only key turning points deserve a separate shot.
14. Dialogue: the speaker must get their own shot focused on their face (lip-sync requirement); add a listener-reaction shot only at key emotional beats.
15. Output an integer `duration` (seconds, 4-12) for EVERY panel, matched to content density: 4-5s for ordinary action/dialogue/reaction shots, 6-8s for establishing/emotional/atmosphere shots, 8-12s for epic or complex staging. Never output the same value for all panels.
16. ⚠️ NARRATIVE-TYPE RECOGNITION (highest priority, prevents spatial jumps): Before planning, classify the source text. It may be "live action/dialogue happening now" OR "memory / legend / voiceover / backstory". The two must be handled differently.
    - Live action/dialogue: concrete time-place, continuous action, on-scene interaction ("He walked in and said…").
    - Memory/legend/voiceover/backstory: summary, hearsay, background, inner monologue ("It was said he once…", "He recalled…", "He improved the toilet because he had once fallen into a pit").
    - For "memory/legend/voiceover" text, DO NOT fabricate a separate real-world location per sentence. ❌ Wrong: each legend becomes its own invented spot (pit → "latrine", poem → "school gate"), producing unrelated jump-cuts.
    - ✅ Correct: compress the whole memory/legend/voiceover into 1-2 shots using "voiceover + indicative imagery (flashback/montage)", all anchored to ONE space-time (e.g. the narrator's current location). Pick at most 1 representational visual for a concrete recalled scene; fold the rest into the voiceover.
